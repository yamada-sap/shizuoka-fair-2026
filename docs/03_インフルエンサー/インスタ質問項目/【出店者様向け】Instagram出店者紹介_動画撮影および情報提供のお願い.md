# 静岡産業フェア2026 公式Instagram

## 出店者紹介動画 素材撮影および情報提供に関するご案内（案）

---

## 1. 本施策の目的

静岡産業フェア2026の公式Instagramアカウントにて、各出店店舗の魅力（取扱商品・体験メニュー・職人技術等）を短尺動画（リール）で紹介し、来場促進および出店者様の集客・PR支援を行います。

### 運用方針（ご確認・ご了承事項）

- **素材提供方式の採用**：事務局では現地取材・撮影は行いません。各出店者様ご自身でスマートフォン撮影いただいた動画素材をご提出いただきます。
- **簡易撮影による負担軽減**：出店者様の作業負担を最小限とするため、10カット程度（難しければ5カット以上）（1カットあたり5〜10秒）の短い固定映像をご提供いただきます。編集・加工は不要です。
- **事務局による編集・配信**：ご提供いただいた素材を運用チームが編集し、テンポ感のある公式PR動画として配信します。

## 3. 動画素材の撮影要綱

出店者様からご提供いただいた動画素材をもとに、事務局にてPR動画を制作いたします。

> **事務局による現地取材・撮影について**
> 事務局・運用チームでは、各店舗様への現地取材・撮影は**実施しておりません**。
> 恐れ入りますが、各出店者様ご自身での撮影・素材提供にご協力をお願いいたします。

### 基本仕様

| 項目          | 内容                                                                      |
| :------------ | :------------------------------------------------------------------------ |
| 撮影の向き    | スマートフォン**縦向き**（9:16 縦画面）                                   |
| カット数      | **10カット程度**（難しければ**5カット以上**）                             |
| 1カットの長さ | **5〜10秒程度**                                                           |
| 撮影環境      | できるだけ**明るい場所**で、事前に**カメラレンズを拭いて**ご準備ください  |
| 編集の有無    | 文字入れ・BGM・カット編集等は**不要**（無加工の元データをご送付ください） |

---

## 4. 撮影対象の例

以下の中から、撮影可能なものを**10カット程度**（難しければ**5カット以上**）お送りください。

- 店舗・会社の外観（看板・入口など）
- 店内や施設の様子（全体の雰囲気がわかるもの）
- 販売中の商品・提供サービス
- 商品の製造過程・作業風景（職人の手元など）
- スタッフの接客風景・働いている様子
- 一押しの商品・サービス
- その他、店舗や事業の魅力が伝わるシーン

> **素材数についてのお願い**
> 使用できる素材が多いほど、編集の幅が広がり、動画としてのクオリティが向上します。結果として再生数やエンゲージメント（いいね・保存・シェア等）の伸びにもつながりますので、ぜひ多めの撮影にご協力ください。

---

## 5. 撮影時のお願い（4つのルール）

### ルール1：カメラを固定して撮影する

撮影中はカメラを振ったりズームしたりせず、**構図を決めて5〜10秒間固定**してください。

### ルール2：「全体」と「アップ」の両方を撮る

同じ被写体でも、**全体の雰囲気がわかる映像**と**近づいたアップの映像**の両方があると、動画の仕上がりが格段に向上します。

### ルール3：環境音はそのままで撮影する

調理音・作業音・接客中の会話など、**自然な音はそのまま活用**します。静かな環境を用意いただく必要はありません。
※スタッフ同士の私語など、映像と無関係な音声が入らないようご配慮ください。

### ルール4：撮影した動画は無加工のまま提出する

編集・加工・BGM追加・文字入れは事務局にて行います。**撮影した元動画をそのまま**ご提出ください。
