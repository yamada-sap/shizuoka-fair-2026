# 📊 【協議・検討資料】
## 静岡産業フェア2026 公式Instagram
### 出店者紹介投稿の構成案および素材収集方針

**作成日: 2026年9月15日**
**担当: 公式Instagram運用チーム**

---

## 📋 本資料の目的

インフルエンサー/SNS運用担当会社より受領した「出店者紹介投稿に関する提案・素材収集要綱」を踏まえ、**掲載可能店舗数の調整および投稿構成案の協議・決定**を行うための説明資料です。

---

## 💡 受領内容のポイントと背景

1. **出店者向け案内資料の整備完了**
   - 「店舗・商品確認項目（テキスト）」および「動画撮影のお願い」の依頼要綱を受領。
2. **投稿本数の上限による制約**
   - 予算・制作本数の兼ね合いから、全出店店舗の個別単独紹介は難しい可能性が高い。
3. **掲載構成の決定が必要**
   - 出店者総数およびジャンル内訳を踏まえた掲載方針の選択が求められている。

---

## 🔍 投稿構成案の比較（協議事項）

運用チームより提案された2つの構成案についての比較です。

| 項目 | 案A：個別店舗紹介型 | 案B：ジャンルまとめ型（推奨） |
| :--- | :--- | :--- |
| **特徴** | 1動画につき1店舗をじっくり紹介 | 「飲食」「ものづくり」等カテゴリ毎にまとめ紹介 |
| **掲載店舗数** | **全体で5店舗程度**（一部抜粋） | **1動画あたり3〜5店舗**（計15〜20店舗程度可能） |
| **メリット** | 各店舗の魅力を深掘りできる | より多くの出店者を紹介でき公平性が高い |
| **デメリット** | 紹介できない出店者が多数発生する | 1店舗あたりの露出時間が短くなる |

---

## 🎯 運用チームとしての推奨方針・提案

### 推奨案：ハイブリッド型 運用プラン
1. **メイン紹介（ジャンルまとめ動画）**:
   - 飲食・クラフト・体験などのジャンル別に**1動画3〜5店舗**をまとめたリール動画を制作。
   - より多くの出店店舗を網羅してPR。
2. **ストーリーズでの全店舗補完**:
   - リール動画で取り上げきれなかった店舗についても、出店者から回収した写真・動画をストーリーズで全店舗順次リポスト・紹介。
3. **出店者への案内タイミング**:
   - 構成案の確定後、出店者へ「動画撮影および情報提供」の依頼を一括展開。

---

## 🗓今後の進め方・スケジュール

```

    │

    │

    │

```
