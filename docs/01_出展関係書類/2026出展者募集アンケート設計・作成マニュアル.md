# 📋 産業フェアしずおか2026出展者募集アンケート設計・作成マニュアル

---

## 1. フォームの新規作成と基本設定

まずはGoogleフォームを新規作成し、タイトルと説明文を設定します。

1. **Googleドライブ**（事務局の共有アカウント）にログインします。
2. 左上の「**新規**」 ➔ 「**Google フォーム**」 ➔ 「**空白のフォーム**」をクリックします。
3. フォームのタイトルと説明を以下のように設定します。
   - **フォームのタイトル**: `【産業フェアしずおか2026】出展申込アンケート`
   - **フォームの説明**:

     ```text
     「産業フェアしずおか2026」の出展申込および事前アンケートフォームです。
     必要事項をご入力の上、送信してください。

     【募集期限】2026年9月11日（金）23:59まで
     ※送信後も、送信完了メールに記載された「回答を編集」リンクから内容の修正が可能です。
     ```

## 3. システム・管理者側で処理する項目（管理用項目）

以下の項目は、回答者が入力するのではなく、Googleスプレッドシートや管理データベース側で処理・記録を行います。

- **回答番号**: 送信時にシステムで自動採番される一意のID
- **受付番号**: 重複しないユニークな受付番号（関数等で自動生成）
- **回答日時**: 送信時のタイムスタンプを自動記録
- **利用者番号**: ログインアカウントIDを自動紐付け
- **申請方式**: 申請ルート（Web申請 / 代理登録 など）
- **申請状況**: 事務局審査ステータス（申請中 / 差戻し / 受理済）
- **申請状況補足**: 差戻し理由などの管理者用メモ
- **処理状況 / 処理状況補足**: 事務局内の対応フェーズ管理用（未処理 / 完了など）

## 4. フォームの全体設定 ＆ 公開手順

### ⚙️ 設定タブでの調整

フォーム上部の「**設定**」タブから以下を設定します。

- **回答の編集を許可する**: **ON（有効）** （※出展者が自己修正できるようにするため）
- **組織制限（〇〇のユーザーに限定する）**: **OFF（無効）** （※外部企業がアクセスできるようにするため）
- **回答を 1 回に制限する**: **OFF（無効）**
- **ファイルのアップロード容量制限**: フォーム全体のアップロード容量（デフォルト1GB）が不足しないよう、必要に応じて「10GB」や「100GB」に引き上げます。

## 3. システム・管理者側で処理する項目（管理用項目）

以下の項目は、Googleフォームの回答者が直接入力することはありません。
送信されたデータを受け取った後、スプレッドシートや管理用データベース側で自動採番、または管理者が手動で更新・処理を行うための項目設計です。

| 項目名           | 役割・データ型                             | 処理方法                                                           |
| :--------------- | :----------------------------------------- | :----------------------------------------------------------------- |
| **回答番号**     | 数値（一意のID）                           | 回答が送信された際にシステム（Googleスプレッドシート等）で自動採番 |
| **受付番号**     | 文字列 / 数値                              | 重複しないユニークな受付番号を関数等で自動生成                     |
| **回答日時**     | タイムスタンプ（日付時間）                 | 送信時の日時を自動で記録                                           |
| **利用者番号**   | ユーザーID                                 | ログインしている場合、ユーザーのアカウントIDを自動紐付け           |
| **申請方式**     | 区分（例: Web申請 / 代理登録）             | 申請ルートをシステム側で自動識別                                   |
| **申請状況**     | ステータス（例: 申請中 / 差戻し / 受理済） | 管理者が申請内容を審査し、スプレッドシート側で手動更新             |
| **申請状況補足** | テキスト（複数行）                         | 差戻しを行う場合の理由などを管理者が記入                           |
| **処理状況**     | ステータス（例: 未処理 / 処理中 / 完了）   | 事務局内での対応フェーズを管理者が更新                             |
| **処理状況補足** | テキスト（複数行）                         | 対応履歴や注意書き等を管理者がメモとして使用                       |

## 4. フォームの全体設定 ＆ 公開手順

すべての設問作成が完了したら、フォームの動作・公開に関する設定を行います。

### ⚙️ 設定タブでの調整

フォーム上部の「**設定**」タブをクリックし、以下の通り設定します。

#### ① 回答の設定

「**回答**」のプルダウンを展開し、以下を設定します。

- **回答の編集を許可する**: **ON（有効）**
  - ※出展者が申込送信後、内容に誤りや変更があった場合に自己修正できるようにするため必須です。
- **制限：〇〇（あなたの組織名）のユーザーに限定する**: **OFF（無効）**
  - ⚠️ **重要**: これがONになっていると、外部の企業がフォームを開けなくなります。必ずOFFにしてください。
- **制限：回答を 1 回に制限する**: **OFF（無効）**
  - ※Googleアカウントのログインを必須にしないことで、出展者の回答ハードルを下げます。誤入力を防ぐためには、上記の「回答の編集を許可する」をONにすることで対応します。

### 🔗 公開用URLの発行

1. 画面右上の「**送信**」ボタンをクリックします。
2. 送信方法で「**リンク**」（チェーンのアイコン）タブを選択します。
3. 「**URL を短縮**」のチェックボックスにチェックを入れます。
4. 生成された短縮URL（例: `https://forms.gle/...`）をコピーし、募集要項のメールやWebサイトに掲載してください。
