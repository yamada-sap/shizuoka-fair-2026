# ⚙️ Google Apps Script (GAS) 自動返信メール＆トリガー設定手順

「産業フェアしずおか2026」の出展申込フォーム送信時に、回答者へ自動で受付完了（控え）メールを送信するための設定手順です。

---

## 1. GASコードの貼り付け

1. 該当するGoogleフォームの編集画面を開きます。
2. 画面上部の「**回答**」タブを選択し、「**スプレッドシートにリンク**」をクリックして回答用スプレッドシートを開きます。
3. スプレッドシートの上部メニューから **「拡張機能」 ➔ 「Apps Script」** をクリックします。
4. 元から入力されている `myFunction()` のコードをすべて消去し、[confirm_and_send_email.gs](file:///Users/sap220701/Desktop/産業フェア_ローカル/docs/01_出展関係書類/confirm_and_send_email.gs) のコードをコピーして貼り付けます。
5. プロジェクト名（例: `産業フェア2026自動返信`）を入力し、ツールバーの **「保存」アイコン（フロッピーディスクマーク）** をクリックします。

---

## 2. 送信テストと初回承認（必須）

GASからメールを送信するには、Googleアカウントによるアクセス承認が必要です。トリガーを設定する前に、手動でテスト実行して承認を済ませておきます。

1. GASエディタの上部メニューで、実行する関数として `onFormSubmit` が選択されていることを確認します。
2. **「実行」** ボタンをクリックします。
3. 「承認が必要です」というダイアログが表示されるので、**「権限を確認」** をクリックします。
4. フォームを運用するGoogleアカウントを選択します。
5. 「このアプリは Google で確認されていません」という警告画面が表示されたら、左下の **「詳細」** ➔ **「（安全ではないページ）に移動」** をクリックします。
6. アクセス許可のリクエスト画面で **「許可」** をクリックします。
7. 実行ログに「イベントデータが存在しないか〜」というログが出力されれば、初回承認は無事完了です（正常な動作です）。

---

## 3. トリガー（送信フォーム連携）の設定

フォームが送信された際に、自動的にプログラムが動くようにイベントトリガーを設定します。

1. GASエディタの左メニューにある **「トリガー」（時計のアイコン）** をクリックします。
2. 画面右下の **「＋ トリガーを追加」** ボタンをクリックします。
3. 設定ダイアログで以下の通り設定します。
   * **実行する関数を選択**: `onFormSubmit`
   * **実行するデプロイを選択**: `Head`
   * **イベントのソースを選択**: `スプレッドシートから`
   * **イベントの種類を選択**: `フォーム送信時`
   * **エラー通知設定**: `毎日まとめて通知`（または任意の間隔）
4. **「保存」** をクリックします。
5. 再度アカウント選択および権限の承認画面が出た場合は、同様に「許可」を行ってください。

---

## 4. 動作確認

1. 作成したGoogleフォームのプレビュー画面から、テスト回答を送信します。
2. 送信した「担当者E-mail」宛に自動返信メールが届くことを確認します。
3. メール本文の宛名（会社・団体名）、お申込内容の控え（出店タイプ、申込数量、計算された合計金額）が正しく表示されているか確認してください。
