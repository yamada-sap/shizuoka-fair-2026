# 📋 産業フェアしずおか2026 出展者募集アンケート項目設計

「産業フェアしずおか2026」の出展要項、および事務局レギュレーションに基づき、出展者募集アンケート（申込フォーム）の項目を整理した設計シートです。
Googleフォームやその他システムでのフォーム作成時にそのままコピー＆ペーストしてご活用いただけます。

## 2. システム・管理者側で処理する項目（管理用項目）

フォームの回答者が直接入力することはありませんが、データベースに紐付けられたり、管理者がステータスを更新・管理したりする項目です。

| 項目名 | 役割・データ型 | 処理方法 |
| :--- | :--- | :--- |
| **回答番号** | 数値（一意のID） | 回答が送信された際にシステムで自動採番 |
| **受付番号** | 文字列 / 数値 | 重複しないユニークな受付番号を自動生成 |
| **回答日時** | タイムスタンプ（日付時間） | 送信時の日時を自動で記録 |
| **利用者番号** | ユーザーID | ログインしている場合、ユーザーのアカウントIDを自動紐付け |
| **申請方式** | 区分（例: Web申請 / 代理登録） | 申請ルートをシステムで自動識別 |
| **申請状況** | ステータス（例: 申請中 / 差戻し / 受理済） | 管理者が申請内容を審査し手動で更新 |
| **申請状況補足** | テキスト（複数行） | 差戻しを行う場合の理由などを管理者が記入 |
| **処理状況** | ステータス（例: 未処理 / 処理中 / 完了） | 事務局内での対応フェーズを管理者が更新 |
| **処理状況補足** | テキスト（複数行） | 対応履歴や注意書き等を管理者がメモとして使用 |
