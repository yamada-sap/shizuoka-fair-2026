# 📋 Googleフォーム作成・GAS設定・運用超詳細作業指示書

## 1. 本指示書の目的と全体概要
本指示書は、「産業フェアしずおか2026」の事務局およびシステム担当者が、出展者向けの「出展申込（エントリー）フォーム（フォームA）」および「出展決定者向け詳細申請フォーム（フォームB）」をGoogleフォームで作成し、自動金額計算・自動返信メールシステム（GAS）を設定・運用するための完全な実務マニュアルです。

ノンプログラマーの作業者でも、本書のステップに従って操作するだけで、プロフェッショナルかつ堅牢なシステムを構築できるように、クリック箇所や設定項目を極めて詳細に書き起こしています。

## 3. 【ステップ1】フォームA：出展申込（エントリー）フォームの作成手順

### 3-1. フォームの新規作成と基本情報設定
1. ブラウザで Google ドライブ（事務局アカウント）を開きます。
2. 画面左上の **「＋ 新規」** ボタンをクリックし、**「Google フォーム」 ➔ 「空白のフォーム」** をクリックします。
3. 画面左上の「無題のフォーム」と書かれた部分をクリックし、フォームのファイル名を `【産業フェアしずおか2026】出展申込フォーム` に変更します。
4. フォームのタイトル（中央の大きな文字）に以下を入力します。
   `【産業フェアしずおか2026】出展申込フォーム`
5. フォームの説明欄に、以下の文章をそのままコピー＆ペーストします。
   ```text
   「産業フェアしずおか2026」の出展申込フォームです。
   必要事項をご入力の上、送信してください。

   【募集期限】2026年9月4日（金）23:59まで

   ※送信ボタンを押した後は、フォームからの回答の修正・再編集は行えません。
   万が一送信後に入力内容の誤りに気づいた場合は、お手数ですが運営事務局（sf-shizuoka2026@shizutetsu-ad.co.jp）まで直接メールにてご連絡ください。
   ```

## 4. 【ステップ2】回答用スプレッドシートの作成とGASの設定手順

### 4-1. 回答用スプレッドシートの紐付け
1. 作成したフォームAの画面上部にある **「回答」** タブをクリックします。
2. 右上にある緑色の **「スプレッドシートにリンク」** アイコンをクリックします。
3. 「新しいスプレッドシートを作成」が選択されていることを確認し、**「作成」** をクリックします。
4. 自動的にスプレッドシートが立ち上がります。

### 4-2. GASコードの貼り付け
1. 開いたスプレッドシートの上部メニューから、**「拡張機能」 ➔ 「Apps Script」** をクリックします。
2. 最初から表示されている `myFunction()` のテキストをすべて削除し、[confirm_and_send_email.gs](file:///Users/sap220701/Desktop/産業フェア_ローカル/docs/01_出展関係書類/confirm_and_send_email.gs) のコードを丸ごとコピーしてエディタに貼り付けます。
3. 画面左上の「無題のプロジェクト」をクリックし、`【しずおか2026】出展申込自動返信` と名前を付けます。
4. エディタ上部の **「保存」アイコン（フロッピーディスクマーク）** をクリックして保存します。

### 4-3. 初回実行と権限の承認（警告画面の解除方法）
GASからGmailを送信するには、Googleアカウントによるアクセス許可が必要です。以下の手順で初回承認を行います。

1. GASエディタの上部メニューで、実行する関数として `onFormSubmit` が選択されていることを確認し、**「実行」** ボタンをクリックします。
2. 画面に「承認が必要です」というポップアップが出たら、**「権限を確認」** をクリックします。
3. 実行するGoogleアカウント（ログインしているアカウント）を選択します。
4. **警告画面（このアプリは Google で確認されていません）**が表示されます。
   - 画面左下にある灰色で目立たない **「詳細」** というリンクをクリックします。
   - その下部に現れる **「【しずおか2026】出展申込自動返信（安全ではないページ）に移動」** をクリックします。
5. 最後に、アクセス権限のリクエスト画面が表示されるので、**「許可」** をクリックします。
6. GASエディタ下部の「実行ログ」に以下が表示されれば承認成功です（引数 `e` が手動実行のため存在しないという正常なログです）。
   `イベントデータが存在しないか、スプレッドシートのフォーム送信トリガーから実行されていません。`

### 4-4. 自動送信トリガーの設定
1. GASエディタ画面の左端にあるメニューから、**時計のマーク（トリガー）**をクリックします。
2. 画面右下の **「＋ トリガーを追加」** ボタンをクリックします。
3. 開いた設定ウィンドウで、以下の通りに値を設定します。
   - **実行する関数を選択**: `onFormSubmit`
   - **実行するデプロイを選択**: `Head`
   - **イベントのソースを選択**: `スプレッドシートから`
   - **イベントの種類を選択**: `フォーム送信時`
   - **エラー通知設定**: `毎日まとめて通知`（任意）
4. 右下の **「保存」** ボタンをクリックします。
5. 再度アカウント選択および権限の承認画面が出た場合は、同様の手順で「許可」を行ってください。

## 6. 【ステップ4】ログイン不要化と再編集禁止の重要設定（必須）

Googleフォームの作成がすべて終わったら、回答者に制限をかけないための設定を必ず適用します。この設定を怠ると、出展者がフォームを開けなかったり、予期せぬデータ変更が発生します。

### 6-1. 設定タブからの設定変更（フォームA・B共通）
1. 各フォーム編集画面の最上部にある **「設定」** タブをクリックします。
2. **「回答」** の項目を展開（右側の ▽ マークをクリック）します。
3. 以下の通り設定を変更します。
   - **メールアドレスを回収する**: `収集しない` に設定します。
     - ※これを「回答者による入力」や「確認済み」にすると、ログインが必須になってしまいます。メールアドレスはフォーム内の設問「担当者E-mail」で直接記述回収するため、ここは「収集しない」で問題ありません。
   - **送信後に回答の編集を許可する**: スイッチを **`OFF`（無効）** にします。（※今回の最重要要件）
   - **制限：[組織名] とその信頼できる組織のユーザーに限定する**: スイッチを **`OFF`（無効）** にします。
     - ※これが `ON` になっていると、組織外の一般出展者がフォームURLを開いた際に「このフォームを表示するには権限が必要です」と表示され、回答できません。必ず `OFF` にしてください。
   - **回答を1回に制限する**: スイッチを **`OFF`（無効）** にします。
     - ※これを `ON` にすると、回答者がGoogleアカウントにログインしていることが必須条件になってしまいます。アカウント非所持の回答者を救済するため、必ず `OFF` にしてください。

## 7. 【ステップ5】動作検証チェックリスト

本番運用を開始する前に、以下の4項目を必ず検証してください。

- **手順**:
  1. フォーム編集画面の右上にある **「プレビュー（目のアイコン）」** をクリックします。

  3. ブラウザの「シークレットウィンドウ」または「プライベートブラウズ」を新しく開き、コピーしたURLを貼り付けます。
  4. **Googleログイン画面を挟まずに、フォームが直接開けば正常です。**

### 検証2：回答修正の制限確認
- **手順**:
  1. テスト回答を入力して「送信」ボタンを押します。
  2. 送信完了画面が表示された際、画面上に「回答を編集」というリンクが表示されていないことを確認します。

### 検証3：金額自動計算とサンクスメール受信確認
- **手順**:
  1. フォームAのテスト送信時に、自分が受信できる「担当者E-mail」を入力します。
  2. 「出店タイプ: 基礎小間」および「申込数量: 2」を選択して送信します。
  3. 送信から数秒〜数十秒後に、指定メールアドレスに以下のメールが届けば正常です。
     - 件名: `【自動配信】産業フェアしずおか2026 企業ゾーン 出展申込を受付いたしました`
     - 本文内の合計金額: `120,000 円` と計算されていること。
     - 本文内に「修正はフォームから行えず、事務局メールアドレスに直接連絡する」旨が記載されていること。

### 検証4：セクション分岐の動作確認（フォームB）
- **手順**:
  1. フォームBのプレビューを開き、「特別設備（電気・火気・危険物）の使用有無」で `なし` を選択して次へ進みます。
  2. **セクション5（特別設備詳細）をスキップして、直接セクション6（広報・協賛）に進むことを確認します。**
  3. 再度テストし、今度は `使用・持ち込み予定あり` を選択して進みます。
  4. **セクション5に進み、詳細入力ができることを確認します。**

## 8. 運用トラブルシューティング

### Q1. 自動返信メールが届かない
* **原因1**: GASのトリガー設定が行われていない。
  - **対策**: Apps Scriptのトリガー画面を確認し、イベントの種類が「フォーム送信時」になっているか再確認してください。
* **原因2**: 回答者がE-mailの入力を誤っている。
  - **対策**: 回答用スプレッドシートを開き、「担当者E-mail」の列の入力アドレスが正しいか確認してください。
* **原因3**: Googleアカウントの送信上限に達している。
  - **対策**: 1日の送信可能枠（ Workspace: 1,500通 / 個人アカウント: 100通 ）を超えている可能性があります。翌日自動復旧します。

### Q2. 出展者が「権限が必要です」と言われてフォームを開けない
* **原因**: 設定タブ内の「[組織名] のユーザーに限定する」が `ON` になっている。
  - **対策**: 設定 ➔ 回答 ➔ 「[組織名] のユーザーに限定する」を `OFF` にしてください。
