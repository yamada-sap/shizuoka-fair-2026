# 🖨️ 産業フェアしずおか2026：印刷物部数・仕様・納期一覧

本イベントで使用するすべての印刷物、ノベルティおよび配布資料の部数、仕様、納期、担当者を一元管理するシートです。

## 🌲 環境配慮（エコスペック）方針について
静鉄グループおよび主催者（静岡市）の環境配慮方針に適合させるため、本イベントで使用するすべての大量印刷物（ポスター、チラシ、リーフレット、報告書、パネル）について、以下のエコスペックを指定しています。
* **用紙**: **「FSC認証森林づくりの紙（再生紙混入率30%以上、マットコート90kg等）」**を採用。
* **インキ**: 石油系溶剤を排除した植物性の大豆油インキ（**SOY INK**）または植物油インキ（**VEGETABLE OIL INK**）を指定。
* **IDカード等**: 塩ビ製ホルダーを廃止し、ストラップ部分に「再生PET素材」、カード本体に「薄型耐水紙」を採用。
