## 全体像

```
【来場者の参加動線】
会場内5ヶ所のQRコード読取 ➔ スタンプ5個達成 ➔ 特典ページからアンケート回答 ➔ 抽選会場へ

【抽選会場スタッフの対応動線】
画面確認（生画面＋完了画面） ➔ スタッフが「特典2」ボタンを押下 ➔ ガラポン抽選実施 ➔ 景品授与
```

> 【重要】現場スタッフ遵守事項
> 1. 特典ページには2つのボタンが表示されます。**来場者自身が操作するのは「特典1（応募フォーム）」のみ**です。
> 2. **「特典2（手渡し引換券）」はスタッフ専用**です。必ずアンケート完了画面を確認した上で、スタッフが操作してください。
> 3. 特典2は一度操作すると取り消しができません（重複抽選防止の電子消込）。
> 4. **参加回数制限の実務判断（会期中お一人様1回限り）**:
>    - **【受付可（初回）】**: 特典2が「特典を受け取る！」（未消込ボタン）になっている場合は、初回の抽選と判断して受付を進行します。
>    - **【受付不可（抽選済）】**: 特典2がすでに赤色で**「特典を受け取り済」**になっている場合は、本日または前日にすでに抽選済みであると客観的に判断し、「お一人様1回限りのため、再抽選はご参加いただけません」とお断りします（端末のCookieにより2日間を通して状態が保持されます）。
> 5. 専用アプリのダウンロードは一切不要です。スマートフォンの標準カメラと標準ブラウザ（Safari／Chrome）のみで動作します。

## 用語定義集（基本概念の整理）

| 用語 | 定義および平易な説明 |
| :--- | :--- |
| **RALLY（ラリー）** | 本企画で使用するデジタルスタンプラリーのクラウドシステム。来場者が閲覧するWeb画面と、本部が利用する管理画面で構成されます。 |
| **スポット** | スタンプを獲得できる物理的な場所。ツインメッセ静岡の会場内5ヶ所に専用QRコードを掲示します。 |
| **特典1（アンケート応募）** | **RALLY「特典応募の流れ（応募フォーム方式）」** に対応する機能（正式名称：①アンケートに答えて応募）。スタンプが5個揃うと押下可能になり、Googleフォームを開いてアンケートに答えてもらうためのボタンです。**来場者本人**が操作します。 |
| **特典2（抽選引換券）** | **RALLY「特典交換の流れ（手渡し方式）」** に対応する機能（正式名称：②抽選引換券（スタッフ専用））。抽選会場にて、スタッフがアンケート回答確認の上で電子消込（もぎり）を行うためのボタンです。**重複抽選の防止**、および**SNS等での画像のみの拡散による不正参加を防止する**ために、必ず**スタッフのみ**が操作します。 |
| **特典を受け取り済** | 特典2のボタンをスタッフが操作した後の画面状態。赤色で「特典を受け取り済」と表示され、再操作は不可能です（1人1回抽選済みの客観的証明）。 |
| **Googleフォーム** | 来場者に回答いただくWebアンケート。Googleアカウントへのログインは不要です。 |
| **送信完了画面** | Googleフォームの回答送信後にブラウザ上に表示される完了メッセージ画面。原則としてこの画面の提示を確認します。 |
| **抽選券（画像）** | 送信完了画面にリンクが貼られた記念用画像。画像単体での抽選は受け付けず、必ずRALLYのWeb生画面（特典2の消込）とセットで確認します。 |
| **Cookie（クッキー）** | 来場者のスマートフォンのブラウザ内にスタンプ獲得状況を一時保持する技術。ブラウザを閉じても維持されますが、履歴削除やプライベートモードでは消失します。 |
| **復元用QRコード** | 端末の予期せぬ不具合等でスタンプが消失した際にデータを復旧するための専用コード。本部にて例外対応時に活用します。 |

# 第1部：現場スタッフ編

## 第1章　全体像と運用方針

### 1-1　本企画の目的と概要
産業フェアしずおか2026では、来場者に会場内の多様な出展ブースを広く回遊していただき、同時に来場者アンケートを収集することで、イベント満足度の向上と次回開催に向けたマーケティングデータを収集することを目的としてデジタルスタンプラリーを実施します。

- **開催会場**: ツインメッセ静岡 会場内
- **開催期間**: 2026年11月28日(土)・29日(日) 両日とも9:30〜17:00
- **スタンプラリー・抽選受付時間**: **両日とも 9:30〜16:00終了（閉場1時間前に完全締切）**
- **設置スポット数**: 合計5ヶ所（北館大展示場 2ヶ所、南館大展示場 2ヶ所、プロムナード 1ヶ所）
- **達成条件**: 5ヶ所すべてのスタンプを獲得（5/5個）
- **参加特典**: アンケート回答者全員に、豪華景品が当たる大抽選会（ガラポン等）への参加権利を進呈
- **参加回数制限**: **会期中を通してお一人様1回限り**（システムの仕様上、一度特典を受け取ると再参加はできません。現場スタッフは「特典2がすでに『特典を受け取り済』になっているか」を目視確認して判定します）

### 1-2　来場者の参加から抽選までの全体フロー

```
[ステップ1] QRコード読取 ➔ 各スポットを巡り、スタンプを5個集める（来場者）
   ▼
[ステップ2] 特典1を押下 ➔ Googleフォームのアンケートに回答・送信する（来場者）
   ▼
[ステップ3] 抽選会場へ来場 ➔ 特典画面およびアンケート完了画面を提示（来場者）
   ▼
[ステップ4] スタッフ確認・消込 ➔ 特典2ボタンをスタッフが操作・確認しながら押下（スタッフ）
   ▼
[ステップ5] 抽選実施・景品授与 ➔ ガラポンを回し、景品をお渡し（来場者・スタッフ）
```

### 1-3　特典1と特典2の機能定義・運用区分
スタンプが5個集まった後の特典ページには、2つの特典ボタンが縦に並びます。これは**「重複抽選の防止」**と**「SNS等での画像のみの拡散による不正参加の防止」**を両立するための重要設計です。スタッフ全員がこの役割の違いを完全に把握しておく必要があります。

| 比較項目 | 特典1（アンケート応募） | 特典2（抽選引換券・スタッフ専用） |
| :--- | :--- | :--- |
| **RALLYシステム機能** | **特典応募の流れ（応募フォーム方式）** | **特典交換の流れ（手渡し方式）** |
| **主な目的** | **アンケートに答えてもらう** | **抽選会場でスタッフが確認・消込を行い、重複や画像拡散を防ぐ** |
| **正式名称** | **①アンケートに答えて応募** | **②抽選引換券（スタッフ専用）** |
| **ボタン表示** | 「特典に応募する！」➔ 押下後「応募済」 | 「特典を受け取る！」➔ 押下後「特典を受け取り済」 |
| **操作担当** | **来場者 本人** | **抽選スタッフ のみ**（スタッフが操作・確認） |
| **操作タイミング** | スタンプ5個達成後、アンケート回答時 | 抽選受付にて回答完了を確認した直後 |
| **遷移先・動作** | Googleフォーム（アンケート画面）が開く | 確認ダイアログが2回表示され「特典を受け取り済」へ変化 |
| **操作の取消** | ― | **不可（一度押すと再発行・巻き戻し不可）** |

> 【現場スタッフが遵守すべき3原則】
> 1. 来場者自身が操作するのは「特典1（応募フォーム）」のみです。「特典2（手渡し）」は絶対に押させないでください。
> 2. 特典2は、アンケート回答完了画面と特典1「応募済」を目視確認してから、スタッフの手で操作します（重複・画像拡散の防止）。
> 3. 特典2は一度操作すると二度と元に戻せません。必ず確認を終えてから落ち着いて操作してください。

## 第2章　来場者の参加手順（スタンプを集める）

### 2-1　参加の開始方法
- 来場者は、スマートフォンの標準カメラアプリを起動し、会場内各スポットに掲示されている「スタンプラリーQRコード」を読み取ることで即座に参加できます。
- 専用アプリのダウンロードや、氏名・メールアドレス等の事前登録は一切不要です。
- 推奨ブラウザ環境：
  - **iPhone**: Safari（標準ブラウザ）
  - **Android**: Google Chrome（標準ブラウザ）

### 2-2　スタンプの獲得手順
1. 各スポットでQRコードを読み取ると、ブラウザでスタンプラリー画面が開きます。
2. 画面上の「スタンプを押す！」ボタンをタップすると、該当スポットのスタンプが画面上に付与されます。
3. スタンプカード画面には、現在の獲得数（例：3/5個）がリアルタイムに表示されます。
4. 会場内5ヶ所のスポットは、どの順序で回っても問題ありません。

## 第3章　特典への応募（アンケート回答〜抽選権の獲得）

### 3-1　スタンプ5個獲得後の画面遷移
5ヶ所すべてのスタンプが集まると、画面下部の「特典」ボタンが有効化され、特典一覧ページへ進むことができるようになります。

### 3-2　特典1の操作とアンケート回答
1. 特典一覧の1つ目にある【特典1：①アンケートに答えて応募】の「特典に応募する！」ボタンを来場者自身に押してもらいます。
2. ボタンを押すと、Googleフォームの来場者アンケート画面が別タブで立ち上がります。  
   ※注意：ボタンを押した時点でシステム上は「応募済」表示に切り替わりますが、この時点ではまだアンケート回答は完了していません。
3. アンケートは選択式を中心とした構成で、所要時間は約1〜2分です。
4. すべての回答を入力後、最下部の「送信」ボタンを押すと、Googleフォームの送信完了画面（サンクスメッセージ）が表示されます。

### 3-3　アンケート送信後の完了画面と提示要件
- Googleフォームの送信完了画面には、抽選会場への案内文とともに、記念用の「抽選券画像（GoogleドライブURL）」および「スタンプラリー画面へ戻るURL」が表示されます。

> 【最重要：確認基準の整合性ルール】
> 抽選受付では、以下の**2要件が揃っていること**を正規の受付基準とします。
> - **必須要件①：RALLYのWeb生画面**（特典1が「応募済」かつ特典2が「特典を受け取る！」の未消込状態）
> - **必須要件②：Googleフォームの送信完了画面**（ブラウザのタブに表示された完了画面）
>
> ※スクリーンショット等の画像単体での提示は一切受付できません。必ず上記2点を確認します。
> ※送信完了画面のタブを誤って閉じてしまった場合の救済手順は「第4章 STEP 1」を参照してください。

## 第4章　抽選会場スタッフの対応手順（最重要）

### 4-1　抽選受付の4ステップ手順
抽選受付では、以下の4ステップを厳格に遵守して進行します。手順の前後は認められません。

```
[STEP 1] スマートフォン画面の目視確認（2要件の確認）
   │  ① RALLY生画面で、特典1が「応募済」かつ特典2が「特典を受け取る！」であることを確認
   │  ② ブラウザの別タブで、Googleフォームの「送信完了画面」を確認
   │  ※特典2がすでに「特典を受け取り済」の場合は ➔ 抽選済みのため受付不可（お断り）
   ▼
[STEP 2] スタッフによる「特典2」の電子消込操作
   │  ①「確認のため、画面のボタンをスタッフが操作いたします」とお声がけ
   │  ② 特典2の「特典を受け取る！」をタップ
   │  ③ 確認ダイアログ1回目：「スタッフが確認の上、特典を受け取りますか？」➔「はい」をタップ
   │  ④ 確認ダイアログ2回目：「本当に受け取りますか？（取り消せません）」➔「はい」をタップ
   │  ⑤ ボタンが赤色の「特典を受け取り済」に変化したことを目視確認
   ▼
[STEP 3] 抽選の実施
   │  ・「確認が完了いたしました。それでは抽選をお願いいたします」とガラポンへ誘導
   ▼
[STEP 4] 景品の授与・お見送り
      ・出た玉の色に応じた景品をお渡しし、感謝の意を伝えて丁寧にお見送り
```

### 4-2　イレギュラー発生時の判断基準

#### ① アンケート完了画面のタブを閉じてしまった来場者
- **状況**: RALLY生画面では特典1「応募済」になっているが、Googleフォームの完了画面タブが見当たらない。
- **対応手順**:
  1. 完了画面に案内されていた「抽選券画像（スクショ）」を所持しているか確認する。所持しており、かつRALLY生画面の特典2が未消込であれば受付可とする。
  2. 画像もない場合は、抽選卓の「予備アンケートQRコード」を読み取ってもらい、その場で回答・送信完了画面を出してもらう（回答完了後に受付可）。

#### ② 来場者本人またはスタッフが誤って「特典2」を押してしまった場合の対応【確定：運営本部承認による救済】
- **状況**: 受付前に来場者が誤って自分で押してしまった、またはスタッフが確認前に誤って押下して「特典を受け取り済」にしてしまった。
- **背景事実（RALLY公式見解）**: 特典2はボタン押下後に確認ダイアログが2回表示されるため誤操作は稀ですが、管理画面からも一度消し込んだステータスを「未受取」に巻き戻すことはできません。
- **確定対応手順（運営本部エスカレーション救済）**:
  1. **現場受付スタッフは独断で抽選を許可しない**: 「画面の確認が必要なため、運営本部へご案内いたします」とお伝えし、インカムで連絡するか運営本部へ誘導する。
  2. **運営本部による客観確認（2要件）**:
     - ① RALLY生画面で5ヶ所のスタンプがすべて集まっていること（会場回遊の事実）
     - ② ブラウザの別タブでGoogleフォームの「送信完了画面」が開かれていること（アンケート回答完了の事実）
  3. **救済の実施**: 上記2点が確認できた場合のみ、運営本部責任者の承認印・指示により**特別に1回ガラポン抽選を許可**する。
  4. **要件を満たさない場合**: アンケート未回答やスタンプ未達の場合はお断りし、ご参加のお礼としてウエットティッシュをお渡しする。

### 4-3　受付時間と終了オペレーション（16:00締切および自動制御）
- **イベント開催時間**: 両日とも 9:30 〜 17:00
- **スタンプラリー実施・抽選受付時間**: 両日とも **9:30 〜 16:00終了（閉場1時間前に完全締切）**
- **16:00の終了時オペレーション（現場対応）**:
  1. 16:00になった時点で、抽選会場では待機列の最後尾にスタッフが立ち、「最後尾看板（本日の受付は終了いたしました）」を掲示して新規の整列を締め切る。
  2. 締め切り時点で列に並んでいるお客様の抽選が終了次第、速やかに抽選受付を終了する。
  3. 各スポット担当または巡回スタッフは、会場内5ヶ所のスポットQRコードに「本日の受付は終了いたしました」の告知札を貼付（または看板撤去・回収）。
- **システム上の自動停止・再開オペレーション（RALLY管理画面操作）**:
  - **1日目（11/28）**: 事前に「スタンプ可能期間」「応募可能期間」を「11月28日 9:30 〜 11月28日 16:00」に設定しておくことで、16:00に自動でスタンプ・応募が締まる。
  - **1日目終了後（夕方）**: 16:00以降に、管理画面の期間設定を**「11月29日 9:30 〜 11月29日 16:00」に1回だけ変更**する。
  - ➔ これにより、**2日目の朝9:30に自動再開し、16:00に自動終了する**ため、当日の手動切り替え忘れによる事故を100%防止できる。

## 第5章　参加者向け注意事項および不正・拡散防止策

### 5-1　役割分担（制作担当・現場スタッフ）
- **制作・広報担当**: ポスター、チラシ、Webサイト、卓上POPに以下の推奨環境および禁止事項を明確に記載・レイアウトする。
- **受付・現場スタッフ**: 口頭案内時や質問を受けた際に、本注意事項に沿って正確にアナウンスする。

### 5-2　参加者への事前周知事項
スタンプラリーの進捗データは、来場者のスマートフォン端末内（ブラウザのCookie）に記録されます。

| 推奨環境・遵守事項 | 禁止事項（データ消失の原因） |
| :--- | :--- |
| ・iPhoneはSafari、AndroidはChromeを使用<br>・最初から最後まで同一のブラウザアプリを使用<br>・歩きスマホは危険なため立ち止まって操作 | ・プライベート／シークレットモードでの参加<br>・ラリー参加途中の閲覧履歴／Cookieの消去<br>・LINEやInstagram等のアプリ内ブラウザでの参加 |

### 5-3　不正拡散防止のための多重防御ルール
「特典1（応募フォーム）」と「特典2（手渡し）」の2段階運用を採用している最大の目的は、**「重複抽選の防止」**と**「SNS等での画像のみの拡散による不正参加の防止」**です。現場では以下の4重防御を徹底します。

1. **画像単体（スクショ）での受付不可**: アンケート完了画面や抽選券画像のキャプチャのみの提示はお断りし、必ず端末ブラウザ上の「RALLY生画面（特典2）」を確認します。
2. **スタッフによる特典2（手渡し）の電子消込**: 生画面上の特典2「特典を受け取る！」をスタッフが操作して「特典を受け取り済」に更新するため、画像の使い回しや他人の画面流用による重複抽選は物理的に不可能です。
3. **サンクス画面での警告掲示**: アンケート完了画面に「※この画面やURLをSNS等で共有することは禁止です。抽選会場ではスタンプラリーのWeb生画面を確認いたします」と明記します。
4. **会期中1人1回制限の徹底**: 2日間の会期を通してお一人様1回限りの参加・抽選とし、重複参加を防止します。

### 6-2　スタンプが消えてしまった場合の対応（想定原因と現場対応）
普通に参加していれば勝手に消えることは滅多にありませんが、ごく稀に「集めたスタンプが消えた！」と申し出る来場者が現れる場合があります。

#### 想定される原因（こんな人）
1. **シークレットモードで開いている人**: ブラウザを閉じた瞬間にデータが全消去される。
2. **LINEなどのアプリ内ブラウザで開いた人**: 途中でアプリを終了した際にキャッシュが消えてしまう。
3. **巡回中に履歴やタブを一括全消去した人**: スマホの動作改善等で履歴をクリアしてしまった。
4. **別のブラウザで開いて消えたと勘違いしている人**: 1ヶ所目と2ヶ所目で別のブラウザアプリを使って開いてしまった。

#### 現場スタッフの対応基準
- 受付列を停滞させないため、抽選会場の受付窓口での長時間の原因調査や復元作業は行いません。
- 「恐れ入りますが、ブラウザの履歴消去やシークレットモード等でデータが消えてしまった場合、受付端末での復元はできない仕組みとなっております」と丁寧にお伝えします。
- **選択肢A（基本対応）**: 「ご参加いただいたお礼として、こちらをどうぞ」と**ウエットティッシュ等をお渡し**し、笑顔でお見送りして完了とします（深追い・もめない対応）。
- **選択肢B（どうしても抽選を受けたいと希望される場合 ➔ 運営本部へ誘導）**:
  - 「回遊の確認ができれば救済できる場合がございますので、運営本部へご案内いたします」とお伝えし、インカムで連絡の上、運営本部へ案内します。

#### 運営本部での迅速救済オペレーション（RALLY推奨ベストプラクティス）
PCで参加者IDを1件ずつ検索して手動付与する方法は現場負荷が大きすぎるため実施しません。代わりに、他社大規模イベントで推奨されている以下の「スマート救済オペレーション」を実施します。

1. **事前準備（運営本部に常備）**:
   - 会場内5ヶ所のスポットQRコードを1枚にまとめた**「全スポットQRコード控えシート（運営本部専用・門外不出）」**を印刷してクリアファイル等に常備しておく。
2. **運営本部での確認手順**:
   - 来場者から「各スポット付近で撮影した写真」を見せてもらうか、どのブースを回ったかを簡単にヒアリングして回遊の事実を確認する。
3. **その場で即時スタンプ再付与**:
   - 運営本部のQR控えシートから、消えてしまったスポットのQRコードを来場者のスマホで直接読み取らせる。
   - ➔ **PC操作やID入力は一切不要で、わずか数秒でスタンプが再付与され、アンケート回答・抽選へ進んでいただけます！**

### 6-3　データの復元の流れ（RALLY公式機能による復旧手順）
万が一、来場者の端末でスタンプや特典の履歴が消えてしまった場合、RALLYには**「復元用QRコードの画像」を使って参加データを元の状態に戻す機能**が備わっています。

```
【事前のバックアップ（来場者側の操作）】
初めてスタンプを獲得した際、画面上に「復元用QRコード」がポップアップ表示されます。
来場者はこの画面のスクリーンショット（画像）を写真フォルダに保存しておきます。
（※画面下部「データの復元」>「復元用QRコードを取得」から後から保存することも可能）
   │
   ▼
【万が一消えてしまった時の復元手順（スタッフ案内用）】
[ステップ1] スタンプラリー画面の最下部にある「データの復元」をタップ
   ▼
[ステップ2] 「ファイルを選択」をタップし、事前に保存した「復元用QRコードのスクショ」を選択
   ▼
[ステップ3] 「データを復元する」ボタンをタップ
   ▼
[ステップ4] 「復元が完了しました。」と表示され、元のスタンプが復旧完了！
```

#### 復元用QRコードを保存していなかった場合の対応
- 事前にスクリーンショットを保存していなかった場合、来場者自身によるシステム的なデータ復元はできません。
- 現場スタッフは「恐れ入りますが、事前の画像保存がない場合はシステム上の復元ができません」と丁寧にご説明し、6-2の基準に沿って**ウエットティッシュ等をお渡しして穏やかにお見送り**してください。
- （※公式ヘルプ参照：https://rallyapp.jp/help/articles/qkh6gx9ke8b0 ）

# 第2部：事務局編

※事務局編（①〜④）は、企画意図およびシステム仕様の記録です。現場スタッフへの配布時には切り離していただいて構いません。

## 事務局編①　ハイブリッド方式の考え方（RALLYに確認済みの運用）

### なぜ「2つの特典」を組み合わせるハイブリッド方式を採用したのか
RALLYの基本仕様では、「特典応募の流れ（応募フォーム方式）」と「特典交換の流れ（手渡し方式）」を1つの特典ボタンで同時に共存させることができません。そこで、2つの特典機能を組み合わせた「ハイブリッド方式」を採用しています。

- **特典1 ＝ 特典応募の流れ（応募フォーム方式）**
  - スタンプを5個集めた来場者に、**Webアンケート（Googleフォーム）に答えてもらう**ための機能です。
- **特典2 ＝ 特典交換の流れ（手渡し方式）**
  - 抽選会場にて、スタッフがアンケート回答を確認した上で**スタッフが直接操作し、電子消込（チケットもぎり）を行う**ための機能です。

### 本ハイブリッド運用の明確な目的
1. **重複抽選の完全防止**
   - スタッフが特典2を操作すると画面が「特典を受け取り済」に変化し、再操作や巻き戻しが一切できなくなるため、1人による複数回の重複抽選を確実に防ぎます。
2. **SNS等での画像のみの拡散による不正参加の防止**
   - アンケート完了画面や抽選券画像のスクリーンショットがSNSやLINE等で第三者に転送・拡散されたとしても、抽選卓では「端末上のRALLY生画面での特典2操作」を必須としているため、画像のみを用いた未参加者の不正抽選を100%シャットアウトできます。

| 比較項目 | 案A：フォーム単独方式 | 案B：手渡し交換単独方式 | 採用案：ハイブリッド方式 |
| :--- | :--- | :--- | :--- |
| **運用方法** | 特典1（応募フォーム）のみ使用。<br>完了画面の画像を見せて抽選 | 特典2（手渡し）のみを使用。<br>アンケートは紙等で別途実施 | **特典1でアンケート回答。<br>特典2でスタッフが消込抽選** |
| **メリット** | スタッフの画面操作が不要。<br>アンケートを確実に集められる | 画面で消し込むため、<br>二重抽選・不正を完全に防止可能 | **アンケート収集と、<br>重複防止＆画像拡散防止を完全両立！** |
| **デメリット・課題** | 画像がSNS等で拡散されると、<br>未回答者も不正に抽選できてしまう | Webアンケートと連動できない。<br>紙の集計コスト・負担が大きい | 特典ページにボタンが2つ並ぶため、<br>事前のスタッフ教育が必要 |

## 事務局編③　RALLYサポートに確認済みの仕様と運用事実（2026年11月18日回答受領）

RALLY公式サポート窓口へ問い合わせを行い、正式に回答・確認が得られた技術的仕様および推奨運用事実です。

| 問い合わせ項目 | 確認された仕様・公式回答事実 | 運用上の決定事項・対応方針 |
| :--- | :--- | :--- |
| **終了時刻の自動制御** | 「スタンプ可能期間」「応募可能期間」を16:00に設定することで、ページを閲覧させたままスタンプ・特典のみ完全自動終了可能。 | 1日目16:00終了後に、管理画面で期間を「11/29 9:30〜16:00」へ1回変更するだけで、2日目朝の自動再開・夕方の自動終了が可能。 |
| **応募フォームと手渡しの併用** | 1つのラリー内で「特典1（応募フォーム）」と「特典2（手渡し）」の2つを設定することは仕様上完全に可能。 | 特典2の注意書きに「スタッフが確認して押下します。事前に押すと無効になります」と明記して誤操作を抑止。 |
| **誤押下の実態と救済対応** | 特典2はボタン押下後に**確認メッセージが2回表示される（ダブル確認仕様）**ため、実際に最後まで誤操作してしまうケースは稀。管理画面からの巻き戻しは不可。 | 他社事例でも「ヒアリングして未受取が確認できれば柔軟に対応するケースが多い」ため、本イベントでも**運営本部にて2点確認（スタンプ5個＋回答画面）の上で救済**を決定。 |
| **スタンプ消失時の現場救済** | 管理画面からの手動ID付与は双方に手間がかかるため非推奨。他社では「写真確認での特別対応」や「窓口での全スポットQR再提示」が主流。 | 運営本部に**「全5スポットのQRコード控えシート」を常備**し、回遊事実を確認の上でその場でQRを再読取させてスタンプを復元する運用を採用。 |
| **通信不安定時のシステム挙動** | オフライン状態ではスタンプ獲得不可（エラー表示）。リロードでは付与されず、電波復帰後に再度現地のQRコードを読み直す必要がある。 | 会場内POP等で「電波が安定した場所でQRコードを読み取ってください」と案内。 |
| **土日イベント中のサポート** | 障害発生時はエンジニアチームへ自動電話通知され、休日夜間問わず対応する体制あり。過去に長時間の停止事故なし。 | 万一のシステム障害時は、運営本部よりお問い合わせフォームを通じて即座に連絡。 |
| **実施データの出力項目** | 累計・日別・時間別の集計データをダウンロード可能。特典1（フォーム）は応募日時をDL可能。特典2（手渡し）は合計から特典1を引いて算出可能。 | 閉場後速やかにCSVおよび応募者データをダウンロードして保管する。 |
