# 産業フェアしずおか2026 デジタルスタンプラリー
## 運営側 決定事項・要相談タスク一覧（人間側で決めること）

作成日：2026年11月17日  
対象：運営事務局・運営責任者・企画担当・進行担当

---

### はじめに
本資料は、「産業フェアしずおか2026 デジタルスタンプラリー」の開催に向けて、**システム側（RALLY）ではなく、主催者・運営関係者（人間側）で検討・合意・決定すべき項目**を整理した検討シートです。

---

## 1. すでに決定・合意した事項（確定ルール）

| 項目 | 決定内容 | 決定理由・背景 |
| :--- | :--- | :--- |
| **受付終了時刻** | **両日とも 16:00 まで** | 閉場（17:00）の1時間前に完全締め切りとし、16:00〜17:00の1時間を待機列の消化、撤収準備、当日の集計に充てるため。 |
| **参加回数の制限** | **会期中を通してお一人様1回限り** | RALLYの仕様上、一度特典を受け取ると端末に記録が残り再参加できないため、システムの自然な挙動に合わせたルールとする。 |
| **景品出尽くし時** | **ウエットティッシュ等をお渡しして対応** | 途中で上位景品が出尽くした場合でも抽選・受付を途中で打ち切らず、アンケート回答者全員へ感謝の品（ウエットティッシュ等）をお渡しして対応する。 |
| **景品の内訳・数量** | **運用マニュアルの対象外** | 景品の具体的な品名や等数・本数は内部企画データであり、現場のオペレーションマニュアルには記載不要のため除外する。 |

## 2. これから運営側で決めないといけないこと（検討・記入シート）

### 【検討事項1】誤って「特典2（スタッフボタン）」を押してしまった人の対応
- **背景**: 特典2は一度押すと取り消しができません。来場者が誤って自分で押してしまった場合の現場ルールを決めます。
- **選択肢**:
  - [ ] **案A（原則徹底・抽選不可）**: 「画面に記載の通り取り消し・再発行はできません」とお断りする（現場のルール統一最優先）。
  - [ ] **案B（本部確認で1回抽選）**: 本部でスタンプ5個やアンケート回答履歴を確認できたら、例外的に1回抽選を認める（顧客満足度重視）。
  - [ ] **案C（代替品対応）**: 抽選はさせないが、ウエットティッシュをお渡しして納得してもらう。
- **決定方針**: ［未定：要選択］

---

### 【検討事項2】スタンプが消えてしまった人の想定原因と対応
- **想定される人物像・原因（滅多に起きないが念のため想定）**:
  1. **シークレットモード利用者**: 普段からプライベート閲覧にしており、ブラウザを閉じると同時にCookieが消えてゼロに戻る。
  2. **LINE等のアプリ内ブラウザ利用者**: LINEのQRリーダーで読み取り、途中でアプリを終了してキャッシュが破棄された。
  3. **途中でタブ・履歴を全削除した人**: 巡回中にスマホが重いと感じて履歴やタブを一括消去してしまった。
  4. **別ブラウザで開いて消えたと勘違いしている人**: 1ヶ所目はSafari、2ヶ所目は別アプリで開いて「さっきのスタンプがない」と申し出る。
- **対応方針（決定案）**:
  - **ウエットティッシュ対応（現場負荷最小）**:
    大掛かりな復元作業は行わず、「履歴やシークレットモードの影響でデータが消えてしまうと復元ができない仕様となっております」と丁寧にお伝えし、ウエットティッシュ等をお渡しして納得・完了としていただく。
- **決定方針**: **ウエットティッシュをお渡しして完了（大掛かりな救済は不要）**
