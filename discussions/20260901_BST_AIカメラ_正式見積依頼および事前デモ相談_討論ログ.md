## 1. 議論・起草の背景と目的

「産業フェアしずおか2026」（2026年11月28日〜29日開催 ＠ツインメッセ静岡）において、来場者カウントおよび属性分析（性別・年代層）を担うAIカメラ（BST株式会社「.BST AIカメラレンタル」）の導入にあたり、メール文面のトーン＆マナーを調整した。

### 主要な調整点
1. **コンタクト履歴の反映**:
   - 初回コンタクト（突然の連絡）ではなく、**「過去に少しメールのやり取りがある関係性」**として挨拶を「いつも大変お世話になっております。先日はメールにてご案内をいただき、誠にありがとうございました。」に調整。
2. **正式見積もり・導入依頼**:
   - これまでの検討はWebサイト等の公開情報を参考にした社内概算検討であった旨を説明し、本番導入に向けた正式見積書の発行を依頼。
3. **初めての導入に伴う事前デモ・10月末展示会での実機テスト相談**:
   - 初めての導入・運用となるため、操作感・検知精度・データ出力フローの確認を目的とした10月末展示会での実機テスト（トライアル）相談（貸出可否、費用、オンライン説明等）。
4. **告知看板の設置事例確認**:
   - 他自治体や大型展示会等のイベントで同様の告知看板を設置された事例・実績の有無を確認。

## 2. 検討論点と対応方針

| 論点 | 検討内容 | 対応方針 |
| :--- | :--- | :--- |
| **① 関係性のトーン調整** | 過去に少しやり取りがある | 「いつもお世話になっております」「先日はメールでのご案内ありがとうございました」とスムーズに導入。 |
| **② 見積前提の適正化** | 概算はネット調査に基づく試算 | Webサイト掲載情報を参考に検討してきた前提を伝え、正式見積書の発行を依頼。 |
| **③ 10月末のテスト費用** | 事前テストに別途費用が発生するか | 無償デモ枠の有無を確認しつつ、有償の場合の概算見積も併せて提示してもらうよう記載。 |
| **④ 運用リスクの低減** | 初めての運用による現場トラブル防止 | オンラインレクチャーや事前画角確認のサポートを依頼し、10月末テストで課題を洗い出す。 |
| **⑤ 看板事例の確認** | 他社事例の有無 | 文言の作成依頼ではなく、他イベント・自治体での設置事例実績の確認に限定。 |

## 3. 次のアクション

1. **ユーザー確認**: 修正したメール文面の確認。
2. **BST社へのメール送信**: 事務局担当者（山田/長島）よりBST社へ送信。
3. **回答回収後の反映**:
   - 正式見積書の受領 ➔ 予算管理表・アライアンス一覧への反映。
   - 10月末テストの可否・日程確定 ➔ 全体進行スケジュール（WMS_Schedule / 詳細タスク管理簿）へのタスク追加。
   - 看板設置事例の受領 ➔ 事務局・デザイン担当（鈴木）への情報共有。
