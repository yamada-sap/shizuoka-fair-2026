# 議論・合意ログ：マニュアルのビジネス文章化および表記ブラッシュアップ

- **日時**: 2026年11月17日
- **対象**: `アンケート/産業フェアしずおか2026_デジタルスタンプラリー運用マニュアル.md`
- **合意事項**:
  - タイトル下の「スリム版」表記を削除し、正式なマニュアルとしての体裁に統一。
  - 導入見出しを「3分でわかる！当日の全体像」から「全体像」へと簡潔化。
  - 全体的な文体（トーン＆マナー）を、絵文字やカジュアルな表現を排除した「ビジネス風かつ明瞭・平易な文章」へと全面ブラッシュアップ。

---

## 1. 文章・用語のブラッシュアップ基準

| 改定前（カジュアル） | 改定後（ビジネスライクかつ明瞭） | 理由・意図 |
| :--- | :--- | :--- |
| **スリム版** | **（削除・正式マニュアル表記）** | 不要な自己言及を排除し、正式な社内資料としての信頼性を担保。 |
| **3分でわかる！当日の全体像** | **全体像** | 簡潔で引き締まったビジネス見出しに変更。 |
| **ここだけ覚える！** | **特典1・特典2の機能定義と運用区分** | 業務指示としての明確性を向上。 |
| **1枚カンペ** | **机上掲示用 抽選受付オペレーションシート** | 現場掲示・配布に適した正式名称へ改変。 |
| **進んでOK / 進んではダメ** | **受付可（進行） / 受付不可（対応保留）** | 判定基準の厳格化・業務基準としての明確化。 |
| **笑顔でお礼！** | **感謝の意を伝え、丁寧にお見送りします** | 接客指示としての品質向上。 |
| **おまけ対応** | **例外・救済対応（本部エスカレーション）** | 現場スタッフの判断負荷を軽減し、統括管理する位置づけを明確化。 |
| **絵文字（⚡, ⚠️, 💡, 🎯, ╔═╗等）** | **ビジネス標準記号（【重要】、［注］、■、▶ 等）** | 公式な業務マニュアルとしての視認性と品位を両立。 |
