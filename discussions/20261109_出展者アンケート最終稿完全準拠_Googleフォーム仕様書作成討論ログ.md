## 2. 原稿内容の完全マッピングとセクション構成設計

### セクション構成（全4セクション）

1. **導入（タイトル・説明文）**
   - タイトル：`産業フェアしずおか２０２６　～ 出展者アンケート ～`
   - 説明文：原稿記載の挨拶文・期限はそのまま活かしつつ、紙用の「□にㇾ点、及びご意見をご記入ください。」のみGoogleフォーム向けに `※ 以下の質問にあてはまる項目を選択、及びご意見をご入力ください。` へ最適化（`【入力期限】2026年11月29日(日)15:00まで`）。
2. **セクション1：基本情報**
   - **出展者名**（記述式・短文）：原稿表面（20行目）の「出展者名」欄に対応。
   - **１　出展ゾーンは**（ラジオボタン）：
     - 選択肢：`地場産業・観光` / `農業` / `しずまえ` / `マグロ` / `林業` / `企業` / `商工会議所` / `中部横断物産ストリート` ＋ Googleフォームの「『その他』を追加」機能で `その他(　　)` を再現。
   - **２　今回で何回目の出展ですか**（ラジオボタン）：
     - 選択肢：`初めて` / `２～３回目` / `４～９回目` / `１０回目以上`
     - **セクション分岐設定**：「回答に応じてセクションに移動」を用い、`初めて` を選択した場合は設問３（2回以上出展の方限定設問）をスキップして**セクション3（設問４）へ自動移動**。`２～３回目`・`４～９回目`・`１０回目以上` を選択した場合は**セクション2（設問３）へ移動**。
3. **セクション2：前回比の売り上げ（2回以上出展の方のみ表示）**
   - **３　２回以上出展されている方で前回に比べ売り上げに変化がありましたか**（ラジオボタン）：
     - 選択肢：`増加した` / `減少した` / `変化なし`
4. **セクション3：売り上げ・客単価**
   - **４　会期中での売り上げはどのくらいですか**（ラジオボタン）：
     - 説明文：`（未集計の場合は概算で結構です）`
     - 選択肢：`販売していない` / `０～５万円未満` / `5万円～10万円未満` / `10万円～30万円未満` / `30万円～50万円未満` / `50万円～100万円未満` / `100万円以上` / `会場での売り上げはほとんどないが会期後の販売につながりそうだ`
   - **５　客単価はどの程度でしたか**（ラジオボタン）：
     - 選択肢：`千円未満` / `千円以上～３千円未満` / `３千円以上～５千円未満` / `５千円以上～１万円未満` / `１万円以上` / `販売なし`
5. **セクション4：出展効果・次回意向・ご意見**
   - **６　今回の出展の効果はありましたか**（ラジオボタン）：
     - 選択肢：`大いにあった` / `少しあった` / `どちらともいえない` / `あまりなかった` / `全然なかった`
   - **７　次回のフェアにまた参加したいですか**（ラジオボタン）：
     - 選択肢：`ぜひ参加したい` / `できれば参加したい` / `わからない` / `参加したくない`
   - **※選択した理由をご記入ください**（段落・長文回答）：
     - 原稿64行目の理由記入欄を、設問７直下の自由記述設問として配置。
   - **８　出展に関して、事務局へのご意見・ご要望などがございましたら以下ご記入ください**（段落・長文回答）：
     - 原稿68行目の自由記述欄を配置。
6. **完了メッセージ（確認メッセージ）**
