# 議論・合意形成ログ：D-1〜D-6（ゴミ汁物・ブレーカー・サンリオ整理券・台車規制・ふわふわ遊具）の運用確定反映

- **対象ファイル**: `スタッフマニュアル/スタッフ用マニュアル_南館_管理・会場メンテナンス（たたき台）.md`
- **合意・確定内容**:
  1. **D-1：ゴミ・汁物処理の一般論対応**:
     - 出展者ゴミ持ち帰り徹底。来場者ゴミ箱は袋二重セット（破れ防止）。
     - トイレ手洗い場や控室Cへの汁捨て厳禁案内。汁物バケツの有無を本部確認。
  2. **D-2：調理・電気ブレーカー落ちの初動**:
     - 「スタッフは分電盤を触らない」を徹底。使用器具のプラグを一旦抜かせ、直ちに運営本部（梅原様宛 無線 `ch23`）へブース番号と状況を連絡。
  3. **D-3：サンリオ整理券（12:30配布・先着200名）の待機列ルール**:
     - ステージ終了（12:30）のアナウンスを合図に整列開始（事前フライング列は作らせない）。
     - ステージ担当と連携し、最後尾案内と200名カウントをサポート。
  4. **D-4：閉場16:00直後のフライング搬出防止（台車走行規制）**:
     - 事務局公式マニュアル（P.20,21）の規定を厳格適用。
     - 「一般来場者が完全に退館し、館内放送の指示があるまで、車両・台車による搬出は全面禁止」。管理担当が出入口等でブース内片付け・梱包を促し、台車走行を制止。
  5. **D-6：ふわふわ遊具（612）周辺の安全対策**:
     - メンテナンス担当の15分周期の定期巡回の中で重点巡回。幼児の急な飛び出し見守り・ベビーカー整頓を実施。
  6. **FAQの拡充**:
     - ブレーカー落ち、汁物廃棄、サンリオ整理券、台車搬出に関する即答フレーズを追加。
