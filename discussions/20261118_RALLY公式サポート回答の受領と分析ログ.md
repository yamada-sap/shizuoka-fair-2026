# 議論・合意ログ：RALLY公式サポートからの正式回答受領と要点分析

- **日時**: 2026年11月18日
- **対象**:
  - `アンケート/RALLYシステム設定・問い合わせ依頼事項まとめ.md`
  - `アンケート/産業フェアしずおか2026_デジタルスタンプラリー運用マニュアル.md`
  - `アンケート/デジタルスタンプラリー特典運用方式_比較検討および誤押下対応方針書.md`

- **RALLY公式回答の受領内容と実務への影響**:
  1. **終了時刻・期間設定（質問1）**:
     - 2日目16:00終了は「スタンプ可能期間」「応募可能期間」を16:00に設定することで、ページを公開したままスタンプ・特典のみ完全自動締め切りが可能。
     - 各日の時間制御（1日目16:00停止 ➔ 2日目9:30再開）は、1日目16:00終了後に管理画面で期間を「11/29 9:30〜16:00」に1回書き換えるだけで、2日目朝の自動再開・夕方の自動終了が実現できる。
  2. **手渡し型誤押下の実態と対応（質問2）**:
     - 管理画面からも巻き戻し・取り消しは不可（仕様確定）。
     - ただし「2回の確認ダイアログ（ダブル確認）」があるため、実際に受け取り済まで誤押下してしまうケースは少ない。
     - 他社事例では「スタッフがヒアリングし、未受け取りが確認できれば柔軟に特典交換に対応するケースが多い（一律お断りのケースもあり）」。
     - 特典紹介文の推奨例：「『特典を受け取る！』ボタンはスタッフが確認して押下します。特典ご利用前に間違えてボタンを押してしまった場合、特典を利用することができなくなりますのでご注意ください。」
  3. **スタンプ消失時の現場救済（質問3）**:
     - 管理画面での個別ID手動付与は「非推奨（手間大）」。
     - 推奨対応案A：復元用QRコード（バックアップ）の活用。
     - 推奨対応案B（他社事例）：**「各スポット付近で撮影した写真などを提示してもらい、行ったことを目視確認して特典交換に対応する」**。
     - 推奨対応案C（他社事例）：**「運営本部に全スポットのスタンプQRコード一覧を用意しておき、確認の上で再読み取りさせてスタンプを付与する」**。
     ➔ これは人手不足の現場にとって極めて有効かつ負荷の低い神運用！
  4. **通信切断（質問4）**:
     - オフラインではスタンプ獲得不可。電波復帰後に再読取が必要。
  5. **土日サポート（質問5）**:
     - フォームから随時受付。システム障害時は休日夜間問わず自動電話通知・エンジニア即時対応体制あり。過去に長時間停止実績なし。
  6. **データ出力（質問6）**:
     - 特典1は応募日時DL可能。特典2は合計から特典1を差し引いて算出可能。保存期限までDL可能。

- **反映方針**:
  - 本回答を各マニュアル・方針書に反映する提案をまとめ、ユーザーに確認・相談を行う。
