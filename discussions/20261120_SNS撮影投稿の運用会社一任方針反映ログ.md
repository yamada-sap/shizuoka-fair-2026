# 議論・合意形成ログ：SNS撮影・投稿の運用会社一任方針の反映

- **日時**: 2026年11月20日
- **対象ファイル**:
  - `スタッフマニュアル/スタッフ用マニュアル_SNS撮影・投稿対応（たたき台）.md`
  - `スタッフマニュアル/スタッフ用マニュアル_総合案内（たたき台）.md`
- **決定事項**:
  - ユーザーより「基本的に撮影等は、運用会社のひとにやってもらう」との明確な指示を受領。
  - **SNSたたき台**：21プロスタッフが自ら撮影する前提を完全に削除し、「SNS運用会社（辻田様・清水様）の当日撮影・投稿進行ガイド 兼 事務局・総合案内との連携確認書」として再定義（S-4も【決定】へ更新）。
  - **総合案内マニュアル**：心得・シフトルール・両日タイムスケジュールから「【SNS担当】による館内撮影・投稿作業」の記述をすべて削除し、21プロスタッフは「窓口対応（常時2名以上／昼前後・ステージ時間中は4名全員配置）に専念し、運用会社の受け入れ・案内サポートのみ行う」形に完全統一した。
