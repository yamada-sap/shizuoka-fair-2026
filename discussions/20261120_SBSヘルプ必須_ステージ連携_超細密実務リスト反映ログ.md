# 議論・合意形成ログ：しずてつストア通路確保・SBSヘルプ必須・ステージ連携および超細密実務リスト反映

- **日時**: 2026年11月20日
- **対象ファイル**: `スタッフマニュアル/スタッフ用マニュアル_南館_管理・会場メンテナンス（たたき台）.md`
- **合意・決定事項**:
  1. **しずてつストア周辺の通路確保**:
     - 来場者・参加者が集中して混雑したケースを想定し、特別企画（しずてつストア アウトレット）周辺のメイン通路確保を正式にスタッフ業務に組み込む。
  2. **1日目 SBS関係のヘルプ（必須タスク）**:
     - 1日目のSBS「だらっと」生中継（午前）および場内生中継レポート（午後）時、カメラクルー・出演者・音声ケーブルの移動動線確保、周辺の来場者整理・安全確保を必須の重点ミッションとして明記。
  3. **ステージ前の通路確保におけるステージ担当との連携徹底**:
     - 南館スタッフが独断で動くのではなく、**ステージ担当（ヨコヤマ商会・21プロ進行フォロー2名）と密に連携・アイコンタクトを取り、指示・合図に合わせて**通路確保・立ち止まり整理・出演者動線誘導を実施する。
  4. **「本当に細かい」現場実務メモ・注意事項の網羅的追加**:
     - ① 出展者からの細かな要求対応（ゴミ袋くれ・テープやペン貸して・机イス追加したい・領収書ほしい・両替してへの即答基準）。
     - ② 来場者からの細かな質問（持参飲食OKか・車椅子ベビーカー貸出・タクシー乗り場・ATM・Wi-Fi）。
     - ③ スタッフ自身の身だしなみ・必携品（腕時計・メモ帳ボールペン・防寒インナー・歩きやすいスニーカー）。
     - ④ 16:00閉場前後の細かな配慮（早仕舞い防止声かけ・16:30一斉通電遮断の事前声かけ）。
     - ⑤ トイレのペーパー切れ・水濡れ発見時の連絡フロー。
