# クライアントプレゼン想定質問・反対意見分析（デビルズ・アドボケイト）討論ログ

- **日時**: 2026年9月14日
- **テーマ**: 「産業フェアしずおか2026」WEBプロモーション統合提案書（PPTX）に対するクライアント（静岡市産業振興協会等）からの想定突っ込み・反対意見・懸念点と口頭カウンターロジックの整理
- **制約事項**: 金額（予算額・単価等）に関する数値情報は全面的に除記・非表示とする。

## 🏛️ クライアント（主催者・審査幹部）側からの想定質問・反対意見 TOP 5

### 1. 「約300万インプレッション出しても、実際に何人ツインメッセに来るのか？（認知と来場者数の接続）」
- **反対意見・懸念**:
  「インプレッション目標はわかるが、WEB広告だけで実際の来場者数増にどう結びつくのか？数字の説得力が不足しているように見える。」
- **口頭カウンターロジック**:
  - WEBプロモーションは「認知・関心喚起」および「特設サイトへの誘導（アクセス・プログラム確認）」を第一目的としています。
  - 単なる認知にとどめず、特設サイト着地後の「無料臨時駐車場・アクセス案内」や「会場内デジタルスタンプラリー」「よしもと・サンリオステージ情報」等と連動させることで、確実なお出かけ意欲の醸成と来場行動への転換を図ります。

### 2. 「配信エリア（静岡県内8市町）が絞られすぎているのではないか？」
- **反対意見・懸念**:
  「なぜ8市町（静岡・焼津・藤枝・富士・島田・吉田・牧之原・富士宮）限定なのか？隣接する沼津市や掛川市などからの集客は狙わないのか？」
- **口頭カウンターロジック**:
  - ツインメッセ静岡への主要アクセス圏（車・公共交通機関で日帰り来場が最も容易なコアエリア）に限定投下することで、遠方への広告流出・無駄打ちを完全に排除しています。
  - 最も来場可能性の高いファミリー層・シニア層に露出を集中させ、リーチの周波数（接触頻度）を高める地域密着戦略をとっています。

### 3. 「なぜ自社Instagram広告は静止画カルーセルなのか？動画を作らない理由は？」
- **反対意見・懸念**:
  「SNSプロモーションなら動画（リール）が主流ではないか？静止画スライドだけで効果が出るのか？」
- **口頭カウンターロジック**:
  - 自社広告では静止画カルーセルを採用することで制作負担を抑え、配信露出枠の確保に注力しています。
  - 一方で、動画での訴求については、提携する人気インフルエンサー（静岡県ニュース速報・おちゃ）が制作したリアルなPRリール動画を、そのまま「Metaパートナーシップ広告（第三者配信）」として二次利用配信するため、高い共感と動画ならではのリーチ力を両立できています。

### 4. 「11/1からの配信開始は早すぎないか？直前集中の方が効くのでは？」
- **反対意見・懸念**:
  - 「11月28・29日の本番に対して11/1からの1か月間配信だと、前半で忘れられてしまわないか？」
- **口頭カウンターロジック**:
  - 子育て世代やお出かけ検討層は、週末の予定を数週間前から組み始める傾向があります。
  - 11月上旬〜中旬で「予定確保（認知・カレンダー登録）」を行い、11月中旬以降にインフルエンサーPRや直前アナウンスを重ねる「認知 ➔ 検討 ➔ 直前想起」の2段階アプローチをとることで、確実な来場予約化を狙っています。

### 5. 「子育て層（サンリオ/芸人）に偏っており、地場産業・伝統工芸の訴求が薄いのでは？」
- **反対意見・懸念**:
  - 「産業フェアの本来の目玉である『地場産業展・伝統工芸・家具・お茶』などを求めるシニア層への配慮が弱く見えないか？」
- **口頭カウンターロジック**:
  - 本提案ではセグメントBとして「50〜70代 一般・シニア層」を明確に分けて設定しています。
  - Yahoo!ニュースやGDNのニュース・伝統工芸・グルメ関連枠にて、地場産業の匠の技、地酒、特産品をメインに押し出した専用クリエイティブ・広告文（Slide 12, 15参照）を独立配信いたします。
