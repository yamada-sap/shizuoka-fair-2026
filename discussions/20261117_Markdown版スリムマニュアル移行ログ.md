# 議論・合意ログ：Markdown版スリムマニュアルへの移行と完成

- **日時**: 2026年11月17日
- **対象**: `アンケート/産業フェアしずおか2026_デジタルスタンプラリー運用マニュアル.md`
- **合意事項**:
  - Word（.docx）による都度生成はAIチケット消費が大きいため、今後は**Markdown（.md）形式**をメインとして推敲・ブラッシュアップを行う方針で合意。
  - 「余分なものが増えた」というフィードバックに基づき、冗長な長文や過剰なテンプレートを削ぎ落とし、現場スタッフ・関係者が1秒で状況判断できる高密度・スリムな構成へブラッシュアップを実施。

---

## 1. スリム化（削ぎ落とし）の主な内容

1. **全体構成の圧縮**:
   - 冗長な前置きや制度解説を全カットし、冒頭に「3分でわかる全体像」と「現場スタッフの絶対ルール」を端的に配置。
   - 役割別の「最初に読む場所」を3行の表に整理。
2. **現場コア業務への集中**:
   - 抽選スタッフの4ステップ（確認 ➔ 押す ➔ 抽選 ➔ 景品）を視覚的なフロー図に集約。
   - 特典1と特典2の違いを1つの対比表に凝縮。
   - 来場者FAQは、現場で実際にアルバイトスタッフが遭遇する8問に厳選。
3. **付録A（1枚カンペ）の強化**:
   - 印刷してブース机上に貼れるアスキーアート枠付きの超シンプルカンペとして再構築（5ステップ＋OK/NGチェック）。
4. **事務局情報の集約**:
   - 事務局編を末尾の「事務局メモ」として1画面分（ハイブリッドの理由、RALLY確認事実、ヘルプリンク）に凝縮。
   - 費用・金額情報は引き続き一切除外。

---

## 2. 今後の運用手順
- 文章の調整や追記・削除はすべて本Markdownファイル上でピンポイント編集（`edit_file`）を実施し、チケット消費を最小限に抑える。
- 最終決定後、紙配布用や提出用として必要となった場合のみ、最終版としてWordやPDFに出力する。
