## 👥 チーム討論ログ（智之さん提案に対する検証）

**【智之さん（プロジェクトリーダー）】**
「アクセスコピーだけど、『ご来場時は、公共交通機関をご利用ください。』でよくない？」

**【推進派：マーケティング・プランナー】**
「ハッとさせられました！おっしゃる通りです！
広告の限られた文字数（15文字・45文字・90文字）の中で、臨時駐車場や提携駐車場の細かい説明をごちゃごちゃ書くよりも、**『ご来場時は公共交通機関をご利用ください』『静鉄電車・バスでスムーズアクセス』**と一言でスパッと伝えた方が、読者にとって圧倒的に読みやすく、メッセージがストレートに届きます！」

**【慎重・反対派：リスク監査役】**
「運営・安全面からも、智之さんの提案が**大正解**です。
ツインメッセ静岡の周辺道路は当日大変混雑します。広告で『車でお気軽にお越しください！駐車場あります！』と強くアピールしすぎると、近隣道路の渋滞悪化や、駐車場に入れない来場者からのクレームリスクが生じます。
主催者（静岡市・振興協会）の公式案内スタンスとしても**『公共交通機関の利用推奨』**が基本原則ですので、コンプライアンスや運営リスク管理の観点からも完全に合致しています。」

**【クリエイティブ派】**

例えばインスタのカルーセル5枚目や広告のアクセス案内文も：

このように1文で簡潔にまとめることで、ビジュアルの余白も生まれて洗練されますね！」

## 🏁 決定事項

1. **広告コピー・案内文のシンプル化**:
   - 広告全媒体（GDN / YDA / Meta）におけるアクセス関連のコピーを、**「ご来場時は、公共交通機関をご利用ください（静鉄電車・バスが便利です）」**を軸としたシンプルかつ明確な表現に統一する。
2. **運営・マナー遵守の徹底**:
   - 会場周辺の渋滞緩和・環境配慮の観点からも、公共交通機関の利用を第一推奨とする主催者スタンスを全広告アセットに適用する。


<script type="module">
  import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@10/dist/mermaid.esm.min.mjs';
  mermaid.initialize({ startOnLoad: false });
  window.addEventListener('DOMContentLoaded', () => {
    document.querySelectorAll('pre code.language-mermaid').forEach((el) => {

      const div = document.createElement('div');
      div.className = 'mermaid';
      div.textContent = el.textContent;
      pre.replaceWith(div);
    });
    mermaid.run();
  });
