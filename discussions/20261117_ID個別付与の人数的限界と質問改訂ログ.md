# 議論・合意ログ：スタンプ消失時のID手動付与に対する人員的実現可能性の判断

- **日時**: 2026年11月17日
- **対象**: `アンケート/RALLYシステム設定・問い合わせ依頼事項まとめ.md`
- **合意された現場判断**:
  - 管理画面から参加者IDを検索して手動付与する機能は存在すると思われるが、**現場のスタッフ人数的に、来場者一人ひとりのIDを聞き取って個別対応することは絶対に不可能（パンクする）**。
  - したがって、RALLYへの質問も「ID手動付与のやり方を聞く」のではなく、**「人手での個別対応が不可能な前提で、現場を停滞させない推奨運用や他社事例を聞く」**形へと改訂する。
