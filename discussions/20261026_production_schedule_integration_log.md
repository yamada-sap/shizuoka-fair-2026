## 1. ユーザー要望と対応方針
制作スケジュールの詳細工程について、1つのセル内テキスト形式ではなく、各マイルストーンを独立した列として一覧できるようにしてほしい旨の指示を受領。

これを受け、以下の9つの工程マイルストーンを独立した列（J列〜R列）として展開した。

---

## 2. 確定した列構成（全20列）

### 【基本仕様・計画】（A列〜I列）
- **A (Col 1)**: No
- **B (Col 2)**: 区分
- **C (Col 3)**: 制作物
- **D (Col 4)**: 種類数
- **E (Col 5)**: 内容
- **F (Col 6)**: 昨年（2025）の実績・仕様
- **G (Col 7)**: 今年
- **H (Col 8)**: 今年の仕様・部数（10/26スケジュール表の最新仕様・部数で補完）
- **I (Col 9)**: 担当（案）

### 【制作スケジュール工程（詳細マイルストーン）】（J列〜R列：背景色アクセント）
- **J (Col 10)**: **原稿受領 / 提供**（制作開始日・素材受領日等）
- **K (Col 11)**: **初稿提示**
- **L (Col 12)**: **初稿戻し**
- **M (Col 13)**: **2稿提示**
- **N (Col 14)**: **2稿戻し**
- **O (Col 15)**: **3稿 / 最終提示**
- **P (Col 16)**: **校了**（太字強調）
- **Q (Col 17)**: **入稿 / 送稿**（太字強調）
- **R (Col 18)**: **納品 / 公開 / 施工**（太字強調）

### 【進捗管理】（S列〜T列）
- **S (Col 19)**: **状況**（完了：薄緑 / 進行中：薄青 / 未着手：薄橙 / 要確認：薄赤）
- **T (Col 20)**: **備考**（日程確定背景、発送同送情報、調整中事項等）

## 3. UI・視認性の改善点
1. **グループヘッダーの新設（行3）**：
   - 「制作物 基本仕様・計画」「制作スケジュール工程（詳細マイルストーン）」「進捗管理」の3ブロックにカテゴリ分け。
2. **工程ブロックのカラーハイライト**：
   - スケジュール工程列（J〜R列）はヘッダー色をディープスレートブルー（`#1E4D6B` / `#2B5B7D`）、データセルを視認性の高い極薄ブルー（`#F4F9FD`）でハイライト。
3. **重要節目（校了・入稿・納品）の強調**：
   - 校了・入稿・納品日はボールドフォント（太字）とし、一覧性を向上。
4. **枠固定の最適化**：
   - `D5` セルでウィンドウ枠を固定し、スクロール時も「No・区分・制作物名」およびヘッダーが常に画面上に維持されるよう設計。
