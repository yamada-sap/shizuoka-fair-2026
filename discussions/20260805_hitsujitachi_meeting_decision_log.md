# 📐 YDP合意形成討論ログ：きのいい羊達様 折衝・基本仕様決定（第1回）

- **対象案件**: 体験型運動教室「きのいい羊達」のプログラム構成・必要機材・転換時間および駐車場手配の決定
- **打合せ日時**: 2026年8月5日（水） 11:00〜12:00
- **作成日（タイムスタンプ）**: 2026年8月5日
- **アサイン部署**: イベント企画・全体設計担当 (`event-content-planner`)、新担当者、イベント運営責任者
- **最終決裁者**: 山田プロデューサー（人間：トモさん）

---

## 🏛️ 組織アーキテクトによる「アーキテクチャ適合宣言」
本討論ログは、最高憲法 v1.8.3 のガバナンスルールに完全に適合していることを宣言します。
最終決裁権（A）は山田プロデューサー単独に固定されています。

---

## 🤸 1. 決定事項：公演構成およびプログラム名

打合せの結果、1日の公演回数を**2公演**とし、ターゲット層に合わせた以下のプログラム名称および内容で決定しました。

* **午前公演（ファミリー向け）**
  * **イベント名案**: **親子で楽しもう！運動あそび**
  * **ターゲット**: 親子で楽しむプログラム
* **午後公演（中高学年向け）**
  * **イベント名案**: **ちびっこ集まれ！運動ゲーム**
  * **ターゲット**: 中高学年を対象としたプログラム

---

## 👥 2. 決定事項：スタッフ体制・転換時間

当日のスムーズな運営および安全確保のため、以下の体制で合意しました。

* **スタッフ要員**:
  * **1日あたり 3〜4人**のスタッフ（インストラクター）体制で運営。
* **転換時間の確保**:
  * 安全な入退場および機材調整のため、公演前後に**前5分・後ろ5分の転換時間**を確実に確保する。
  * この転換時間はタイムテーブル設計時にバッファとして組み込む。

---

## 🎤 3. 決定事項：現場設備・車両手配

ステージおよびバックヤードの物理的な必要要件として、以下を手配・確保することで合意しました。

* **音響設備要件**:
  * 動きながらの指導・実演となるため、**ヘッドセットマイク**が必要。
  * 音響オペレーターおよび会場施工チームと連携し、必要数を手配する。
* **車両用駐車場**:
  * 器具の搬入およびスタッフ移動用として、**駐車場を2台分**用意する。
  * 事務局にてツインメッセ静岡内の出展者用駐車場（または関係者駐車場）を確保する。

---

## 🤸 4. 決定事項：ステージプログラムの主な流れ・備品手配

打合せにて合意された、ステージ進行の主なタイムラインおよび備品手配の役割分担は以下の通りです。

| プログラム（目安時間） | 内容・アクティビティ |
| :--- | :--- |
| **挨拶・自己紹介 (3分)** | 各先生が特技を生かして自己紹介を行う |
| **準備体操 (3分)** | 音楽に合わせて準備体操を行う |
| **ウォーミングアップ (5分)** | カラーボールまき、その場かけ足、真似っこゲーム |
| **徒手あそび (5〜10分)** | 高い高い、ゆらゆら抱っこ、手押し車、手押し相撲、亀ひっくり返し対決、ハンドパワー |
| **親子あそび (10〜15分)** | レジ袋あそび、ホースあそび、新聞紙あそび、面白シート |
| **サーキットあそび (10〜15分)** | 鉄棒、ジャンプ台、とび箱、ケンケン、パンチングボンボン |
| **運動ゲーム (10〜15分)** | 的あてゲーム、鬼退治、ロボット鬼ごっこ、バクダンゲーム、おすもう対決、マット取りゲーム、とうせんぼゲーム、モグラゲーム |

* **備品手配の役割分担**:
  * 運動あそび・サーキット・ゲームで使用する各種備品・遊具（マット、鉄棒、とび箱等）は、すべて**きのいい羊達様側で準備・持ち込み**となります（事務局側での手配・用意は不要）。
