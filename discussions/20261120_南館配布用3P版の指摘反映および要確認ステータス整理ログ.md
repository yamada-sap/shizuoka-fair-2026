# 議論ログ：南館配布用3P版の指摘反映および要確認ステータス整理

- **日時**: 2026-11-20
- **参加者**: ユーザー, アシスタント
- **目的**: 
  1. ユーザーからの具体的指摘に基づき、配布用3P版およびたたき台の記述を精査・是正。
  2. 不要な自主巡回タスク（通電確認・困りごと吸い上げ等）の削除、人名表記の排除とインカム・電話番号への統一。
  3. 閉場後の搬出規制に関するエビデンス確認と手引き準拠への修正。
  4. 休憩スペース常駐と定期巡回の両立性課題、清掃道具配備の有無、しずてつストア・ステージ混雑緩和の反映。

## 1. ユーザー指摘と対応・反映内容

| No | 指摘箇所・内容 | 対応・マニュアル反映内容 |
| :---: | :--- | :--- |
| **1** | **L15の削除** | スタッフ心得3原則の「3. 迷ったら無線ch23へ連絡」を削除（緊急連絡先に記載済みで重複のため）。 |
| **2** | **L30 出展者対応** | 自主的な全ブース通電チェックを廃止。「出展者パスの着用確認。通電チェック等は出展者から問い合わせがあった場合に本部と連携」に修正。 |
| **3** | **L31 困りごと吸い上げ** | 「出展者の困りごと吸い上げ」を削除（わざわざスタッフから吸い上げる必要なし）。 |
| **4** | **L36 特定の名前を出さない** | 「梅原様」などの個人名表記を完全排除。「困ったら、インカム連携（無線 `ch23`）または運営本部臨時電話（`080-1607-7670`）へ連絡」に統一。 |
| **5** | **L38 搬出規制のエビデンス** | 公式『出展の手引き』Slide 8に「撤去・搬出作業 16:30〜（注意事項：来場者退館後）」と明記。「台車走行全面禁止・放送まで待機」は手引き記載の事実ではなく推測であったため、公式ルール通り「16:30〜搬出作業開始（来場者退館優先）」に修正。 |
| **6** | **L45 残汁ペール缶** | 「本部確認中」から**【要確認】**ステータスに表記統一。 |
| **7** | **L46 休憩スペース常駐要否** | **【要確認】**ステータスに表記統一。 |
| **8** | **L47-L48 常駐と巡回の両立性** | 休憩スペースに常駐すると15分毎の通路巡回ができないため、「休憩スペース常駐とフロア巡回の分担・バランスは【要確認】」として実態に即して整理。 |
| **9** | **L50 清掃道具の有無** | モップやバケツ等の清掃用具の有無について**【要確認】**ステータスを明記。 |
| **10** | **L51 混雑緩和** | 「しずてつストア（特別企画）やステージコンテンツ周辺の混雑緩和・動線確保」を会場メンテナンス・管理の重要業務として正式明記。 |
